ShopEase E-Commerce QA Project
================================

This package is a PRACTICAL QA PORTFOLIO / TRAINING PROJECT, not evidence of employment on a real client project.

Contents
--------
01_Test_Scenarios.xlsx - Manual test scenarios by module
02_Test_Cases.xlsx     - Detailed functional test cases
03_Test_Data.xlsx      - Sample test data
04_Bug_Reports.xlsx    - Example/simulated defect reports
05_RTM.xlsx             - Requirements Traceability Matrix
06_Test_Execution.xlsx - Sample execution results for practice
07_Test_Summary.xlsx   - Sample test summary

Recommended workflow
--------------------
1. Pick a permitted demo e-commerce web application.
2. Execute the test cases yourself.
3. Replace "Not Executed" with Pass/Fail/Blocked.
4. Record only defects you actually reproduce.
5. Update the RTM and execution report.
6. Prepare a final test summary based on actual results.
7. Keep the project description honest in your resume/GitHub:
   "E-Commerce Web Application - QA Testing Personal Practical Project."

Important
---------
The bug reports and execution results in this package are illustrative/simulated. Do not tell an interviewer that these bugs were found in a production/client system unless you actually reproduced them in a real test environment.
